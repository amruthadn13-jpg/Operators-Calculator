Overview

This project demonstrates the use of operators in C++. It accepts two integer values from the user and performs arithmetic, relational, logical, and assignment operations. The application is designed to provide a practical understanding of how operators are used in real-world programs.

Objectives

The objectives of this project are to:

Understand the role of operators in C++
Perform arithmetic calculations
Compare values using relational operators
Evaluate conditions using logical operators
Modify values using assignment operators
Build an interactive console-based calculator
Concepts Covered
Arithmetic operators (+, -, *, /, %)
Relational operators (==, !=, >, <, >=, <=)
Logical operators (&&, ||, !)
Assignment operators (=, +=, -=, *=, /=)
User input using cin
Formatted output using cout
Program Description

The program prompts the user to enter two integers and then displays:

Arithmetic results:
Addition
Subtraction
Multiplication
Division
Modulus
Relational comparisons:
Equality and inequality checks
Greater than and less than comparisons
Logical evaluations:
Logical AND
Logical OR
Logical NOT
Assignment operation demonstration:
Updating a variable using +=


Learning Outcomes

After completing this project, I gained an understanding of:

How operators manipulate data in C++
The difference between arithmetic, relational, logical, and assignment operators
How to collect and process user input
How to build a structured console application
